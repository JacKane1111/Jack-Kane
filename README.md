# 电机控制 Android 应用 (Motor Control App)

用 **Python + Kivy** 编写,通过 **Buildozer** 编译成 Android 可直接安装的 `.apk` 文件。
应用通过**蓝牙**向控制板(Arduino + 步进电机驱动)发送脉冲信号,驱动电机按设定的长度和数量循环运转。

---

## 功能说明

### 主界面 (MainScreen)
- 6 个按钮,每个大小 **160 × 80** 像素。
- 第 1 个按钮(**Auto**)按下后进入 **Auto 界面**。

### Auto 界面 (AutoScreen)
| 控件 | 说明 |
|------|------|
| 长度1 输入栏 | 单位厘米,决定脉冲时长。点击弹出数字键盘(最多 3 位) |
| 长度2 输入栏 | 单位厘米。点击弹出数字键盘(最多 3 位) |
| 数量 输入栏 | 点击弹出数字键盘(最多 3 位) |
| 剩余数量 显示栏 | **只读**,不能输入,运行时每完成一个减 1 |
| 运行 / 停止 按钮 | 未运行 = **绿色「运行」**;运行中 = **红色「停止」** |

### 运行逻辑
1. 按下**运行**按钮,应用通过蓝牙向控制板发送脉冲信号让电机运转。
2. 单个脉冲时长 = `长度(cm) × 0.001 × 60 ÷ 24`
   - 例:输入 `100` 厘米 → `100 × 0.001 × 60 ÷ 24 = 0.25` 秒。
3. 运行完 0.25 秒后,**间隔 1 秒**,再运行下一个 0.25 秒,同时**剩余数量减 1**。
4. 如此循环,直到所有数量运行完毕,按钮自动复位为绿色「运行」。
5. 运行途中点击**红色停止**按钮,立即终止循环并复位为绿色状态。

## 如何编译成 APK

### 方法一:GitHub 云端自动编译(推荐,无需本地环境)
代码推送后,GitHub Actions 会自动编译。进入仓库网页的 **Actions** 页面 →
选择最新的 **Build Android APK** 任务 → 在 **Artifacts** 中下载 `MotorControl-APK`,
解压得到 `.apk`,传到安卓手机即可安装。

### 方法二:本地编译(需要 Linux 或 Windows 的 WSL)
```bash
# 1. 安装依赖
pip install buildozer cython
sudo apt-get install -y openjdk-17-jdk

# 2. 在项目目录执行编译(首次会自动下载 Android SDK/NDK,较慢)
buildozer android debug

# 3. 编译完成后,APK 在 bin/ 目录下
#    用数据线或蓝牙传到手机安装即可
```

> 安装时若提示「未知来源」,请在手机设置中允许安装该来源的应用。

## 蓝牙通信协议
应用向控制板发送两条简单命令(每条以换行 `\n` 结尾):
- `MOTOR_ON`  —— 电机开始转动(输出脉冲)
- `MOTOR_OFF` —— 电机停止转动

脉冲的**时长由手机 App 控制**(App 发送 ON,等待脉冲秒数后发送 OFF),
因此控制板固件只需响应开/关即可,逻辑简单可靠。

## 🔧 所需硬件清单

| # | 硬件 | 说明 / 型号建议 | 数量 |
|---|------|----------------|------|
| 1 | 安卓手机 | Android 5.0 及以上,带蓝牙,用于安装本 App | 1 |
| 2 | 主控板 | Arduino UNO / Nano(或兼容板) | 1 |
| 3 | 蓝牙串口模块 | **HC-05** 或 HC-06(经典蓝牙 SPP,默认名 HC-05) | 1 |
| 4 | 步进电机驱动板 | A4988 或 DRV8825 步进驱动模块 | 1 |
| 5 | 步进电机 | NEMA17 42 步进电机(或按负载选型) | 1 |
| 6 | 电机电源 | 12V / 2A 直流电源(给驱动板供电) | 1 |
| 7 | 杜邦线 | 公对母 / 公对公若干,用于接线 | 若干 |
| 8 | 面包板 | 便于接线调试(可选) | 1 |
| 9 | USB 数据线 | 给 Arduino 供电与烧录固件 | 1 |

> 若使用普通直流电机而非步进电机,可把驱动板换成 **L298N** 电机驱动模块,
> 并相应修改 `arduino/motor_control.ino` 中的引脚控制逻辑(用 PWM 控制转速)。

### 接线简表(步进电机方案)
| Arduino 引脚 | 连接到 |
|---|---|
| D2 | 驱动板 STEP(脉冲) |
| D3 | 驱动板 DIR(方向) |
| D4 | 驱动板 EN(使能) |
| D10 | HC-05 的 TXD |
| D11 | HC-05 的 RXD(需电阻分压到 3.3V) |
| 5V / GND | HC-05 供电 |
| 外部 12V / GND | 驱动板电机电源 |

---

## 使用步骤
1. 按接线表连接硬件,用 Arduino IDE 把 `arduino/motor_control.ino` 烧录到主控板。
2. 手机蓝牙里先与 **HC-05** 配对(默认配对码 `1234` 或 `0000`)。
3. 安装并打开本 App → 点 **Auto** → 输入长度和数量 → 点绿色**运行**。
4. 电机将按脉冲循环运转,剩余数量实时递减;需要中止时点红色**停止**。
